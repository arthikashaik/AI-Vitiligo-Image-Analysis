# AI-Based Vitiligo Image Analysis

## Candidate Light-Region Estimation Using Image Processing

An educational image-processing prototype developed to explore basic analysis of candidate light regions in skin images.

## 📌 Project Overview

This project uses Python and OpenCV to process an input image and estimate candidate light-region areas using image-processing techniques.

The prototype demonstrates:

- Image loading
- Image preprocessing
- Grayscale conversion
- Threshold-based segmentation
- Candidate light-region detection
- Pixel-based area estimation

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Visual Studio Code

## 📂 Project Workflow

1. Input Image
2. Image Preprocessing
3. Grayscale Conversion
4. Thresholding
5. Candidate Region Detection
6. Pixel Calculation
7. Area Percentage Estimation

## ⚠️ Disclaimer

This is an educational and academic prototype.

It is NOT a medical diagnostic tool and should not be used for clinical diagnosis or treatment decisions.
